# ServiceNow Laptop Request Automation - Naan Mudhalvan

## Project Description
This project automates the laptop request and approval process for employees using ServiceNow.

## Features
- Service Catalog Item for Laptop Request
- Approval Workflow using Flow Designer
- Task Assignment for IT Team
- Email Notifications

## Tools Used
ServiceNow PDI, Service Catalog, Flow Designer

## Steps to Implement
1. Created Custom Table for Laptop Details
2. Created Service Catalog Item with Variables (Laptop Model, Reason)
3. Designed Flow: Request -> Manager Approval -> IT Fulfillment
4. Tested with Demo User
